## MES 형식 (확인)
- 머리 u16 **LE** = 글자 표 끝 위치(2+2n) · 글자 표 = 그 파일의 자주 쓰는 글자 SJIS n자(보통 128)
- 본문 = 스크립트 바이트코드 + 문자열
  - 글자: `0x80+i` 1바이트 = 표[i] · `0x40~0x7F` 첫 바이트 2바이트 = SJIS(첫 바이트 **+0x20**, 둘째 그대로) 예 `62 D1` = び
  - ⇒ 2바이트로 쓸 수 있는 SJIS 는 첫 바이트 0x81~0x9F(JIS 1~62구)뿐 — E0 이상 한자는 표로만
  - 대사: `…03` 뒤 시작 ~ `0C` 앞 끝, «％» = 줄바꿈 · 메뉴·시스템 문장은 `13`/`02`/`00` 앞 끝
- 확인 근거: MACHI1 0x5F03 `96 D6 61 75 62 D1 …` = «村人「びっくりしたなぁ、もう」» = 스샷 4 화면 그대로, 스테이트 4 에서 MACHI1.MES 가 램 **0x060B0000** 에 통째로 적재(SJIS 로 풀어 둔 사본 없음)
- 모든 MES 앞쪽(0x27xx~0x43xx)에 **공용 블록**(메뉴·아이템 설명·전투 문장 등) 같은 내용 반복 — 159 문자열이 20개 이상 파일에 중복
